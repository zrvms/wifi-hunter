# WiFi Hunter 1.0
Мобильное PWA для локальной оценки стойкости пароля и проверки настроек собственного роутера. Не сканирует окружающие сети и не подбирает реальные пароли Wi-Fi. Радар декоративный, лаборатория использует только случайный игрушечный код.

## GitHub Pages
1. Создайте новый публичный репозиторий `wifi-hunter` (не используйте репозиторий другого приложения).
2. В корень репозитория загрузите все файлы из архива, не сам ZIP. Нажмите Commit changes.
3. Settings → Pages → Source: Deploy from a branch → main / (root) → Save. После публикации откройте URL, который GitHub покажет в Pages.
4. В Safari на iPhone нажмите «Поделиться» → «На экран Домой» → включите «Открывать как веб-приложение», если предлагается → «Добавить».

## Локальная проверка
`python -m http.server 8000` из папки проекта. Откройте http://localhost:8000. Для установки на iPhone нужен HTTPS (GitHub Pages). После первой загрузки service worker сохраняет файлы для офлайн-режима. Внешних библиотек и серверной базы нет. Журнал и отметки аудита сохраняются в localStorage; пароли не сохраняются. Оценка пароля приблизительная и не проверяет базы утечек.
