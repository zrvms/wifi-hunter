# WiFi Hunter 2.0
PWA для iPhone. Радар декоративный, реального сканирования Wi-Fi и подбора паролей нет.

- IP Scanner и Lookup: ipapi.co; приблизительная геолокация, OpenStreetMap по кнопке.
- Speed Test: Cloudflare, 3 HTTP-задержки, загрузка 8 МБ, отправка 2 МБ; оценка приблизительная.
- WiFi QR: локальная генерация, QR содержит пароль, не отправляется в сеть.
- Security Check: ручной аудит роутера.
- Network Monitor: HTTP-проверка сервера каждые 15 секунд после ответа при открытом разделе и видимом документе.
- История измерений (до 30 записей каждого типа), журнал и аудит хранятся локально. Пароли и IP в журнале не сохраняются. Внешние сервисы могут ограничивать запросы.

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root). Откройте сайт в Safari → Поделиться → На экран Домой. Для обновления закройте и откройте приложение при подключении к интернету.
